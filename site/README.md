# theeryder.com

Static site for GitHub Pages. No build step is needed to publish: upload the files as they are.

- `index.html`, `work/`, `info/`, `contact/`: pages (generated by `node build.mjs`)
- `css/site.css`, `js/site.js`, `js/timeline.js`: styles, gallery and lightbox, interactive timeline
- `img/<project>/NN.webp`: full size (2000 px) and `NN-s.webp` (1300 px) for grids
- `data/content.json`: all texts, `data/rows.json`: gallery row layout, `data/timeline.json`: timeline

To change text or order, edit the JSON in `data/` and run `node build.mjs`.
The Behance link is set in `data/content.json` (`site.behance`).
